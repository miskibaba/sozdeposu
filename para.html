PARA SÖZLERİ

Para

Para amaç değil, araçtır.

Akıllı yatırım özgürlük getirir.

Kazanç emekle güzeldir.

Para sabırlıyı sever.

Biriktirmek kazanmanın yarısıdır.

Zenginlik önce zihinde başlar.

Paranı yönetmezsen, para seni yönetir.

Risk bilinçliyse kazanç büyür.

Para disiplin ister.

Kazananlar fırsatı görür, korkmaz.
